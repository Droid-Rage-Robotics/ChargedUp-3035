# Team 3035 Robot Code — 2023 Season

## Overview

This repository contains the competition code for Team 3035's 2023 FRC robot, **Angler**, built for the **Charged Up** season.

---

## Season Summary

The 2023 season saw Team 3035 compete at two FIRST in Texas district events, the District Championship, and the World Championship. Throughout the season, Droid Rage demonstrated consistent performance and qualified for the playoffs at every event attended.

### Events Attended

* FIT District Waco Event
* FIT District Channelview Event
* FIRST in Texas District Championship — Apollo Division
* Daly Division
